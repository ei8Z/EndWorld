## Task 1：结算账本持久化（P0-2）

### 方案
用 Prefs（报告允许的“稳定键”），不加 DB 迁移。键 `v3_last_settled_day`，值 = 已完成结算的最后游戏日。

新建 `data/repository/SettlementLedger.kt`：

```kotlin
class SettlementLedger(private val prefs: SharedPreferences) {
    fun load(): Int = prefs.getInt(KEY, 1).coerceAtLeast(1)

    /** 结算成功后再写，commit 保证进程被杀前落盘。 */
    fun mark(day: Int) {
        prefs.edit().putInt(KEY, day).commit()
    }

    companion object { const val KEY = "v3_last_settled_day" }
}
```

`GameRepository`：

- 字段：
  ```kotlin
  private val settlementLedger = SettlementLedger(
      context.getSharedPreferences("endworld_cache", Context.MODE_PRIVATE)
  )
  var lastMidnightSettlementDay: Int = settlementLedger.load()
  ```
  删除原来的 `= 1` 初始化。
- `processMainline` 的结算块：
  ```kotlin
  val pendingDays = pendingSettlementDays(lastMidnightSettlementDay, sm.clock.currentDay)
  if (pendingDays > 0) {
      repositoryScope.launch {
          v3Mutex.withLock {
              repeat(pendingDays) {
                  try {
                      executeDailySettlement()
                      lastMidnightSettlementDay += 1
                      settlementLedger.mark(lastMidnightSettlementDay)
                  } catch (e: CancellationException) {
                      throw e
                  } catch (e: Exception) {
                      Log.e(TAG, "每日结算失败，停在 day=$lastMidnightSettlementDay", e)
                      return@withLock
                  }
              }
          }
      }
  }
  ```
  关键：**不再在启动前把游标置为 currentDay**；逐日成功才前进并落盘。
- `resetV3World()`：`lastMidnightSettlementDay = 1` 后 `settlementLedger.mark(1)`。
