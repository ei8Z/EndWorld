## Task 1：世界事件按区间触发（P1-3）

`WorldEventManager.checkAndTrigger` 现在只匹配 `triggerDay == daysSurvived`，跨天/加速会漏。改为“已到天数且未触发”：

```kotlin
val matched = allEvents
    .filter {
        it.triggerDay <= daysSurvived &&
            doomLevel >= it.doomLevelRequired &&
            it.id !in triggeredEvents
    }
    .sortedBy { it.triggerDay }
matched.forEach { triggeredEvents.add(it.id) }
return matched
```

`triggeredEvents` 已有 seed/getIds，无需新持久化。

测试：`daysSurvived=999, doom=5` 首次返回非空；再次调用返回空（幂等）；一个 `triggerDay=5` 的事件在 `daysSurvived=6` 时能触发。

## Task 3：伤病 HP/SP/感染接线（P1-10）

### VitalSystem

```kotlin
fun applyActionCost(primaryType: String, penalty: Float = 0f) {
    val baseCost = SP_COSTS[primaryType] ?: 0
    val fatigueMultiplier = if (fatigue >= 80) 1.5f else 1.0f
    // 只有消耗（负值）吃伤病惩罚；休息的正向恢复不受影响
    val actualCost = if (baseCost < 0) {
        (baseCost * fatigueMultiplier * (1f + penalty)).roundToInt()
    } else baseCost
    sp = (sp + actualCost).coerceIn(0, spMax)
    clampAll()
}
```

### SurvivalStateMachine

新增：

```kotlin
/** 按整小时推进伤病：HP 损失、自然恢复、感染判定。 */
internal fun tickHours(hours: Int) {
    repeat(hours.coerceAtLeast(0)) {
        val loss = health.calculateHourlyHpLoss()
        if (loss > 0) {
            vital.applyResourceChange(ResourceChange("", "", "生命值", -loss.toFloat(), 0f))
        }
        health.tickHourly()
    }
    health.checkInfection()
}
```

- `processPreRuling`：`repeat(hours.toInt()) { health.tickHourly() }` → `tickHours(hours.toInt())`；`vital.applyActionCost(primaryType)` → `vital.applyActionCost(primaryType, health.calculateSpPenalty())`。
- `processBranchAction`：同样换 `tickHours(hours.toInt())`。
- `GameRepository.advanceAcceleration`：`repeat(hours.toInt()) { stateMachine.health.tickHourly() }` → `stateMachine.tickHours(hours.toInt())`，让加速也吃 HP 损失/感染。
