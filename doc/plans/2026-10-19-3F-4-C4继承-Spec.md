# 3F-4 C4 继承 Spec

> 日期：2026-10-19　｜　状态：待评审
> 上游：`doc/v3/末日求生 · AI 叙事游戏 开发文档 V3.0.md` §7.2/§7.3。
> 用户确认：一键默认继承者；世界全保留；好感 ×0.3；背包与新局一致（空）；历史摘要只展示、不建表、不进提示词。

## 目标

角色死亡后可选择“继承”：新角色以默认初始状态踏入同一个世界，世界状态保留，NPC 对前角色的好感按 30% 折算，时间回到第 1 天；继承完成后展示前代纪事摘要。

## 交互

死亡覆盖层现有「重新开始」旁新增「继承世界」：

- 点击 → 二次确认“创建继承者并保留这个世界？本局角色与背包将重置。”
- 确认 → 禁止重复点击 → 调用 `GameViewModel.inheritWorld()`
- 成功 → 关闭死亡层，展示「前代纪事」卡片（可关闭），并自动发送继承开局行动
- 失败 → 留在死亡层显示错误，不半继承

「重新开始」行为不变。

## 世界保留

保留：

- 势力、区域、全局事件
- 全部 NPC：身份、去向、需求、记忆、KEY 层级
- NPC 对关系 `npc_pair_relations`
- 已触发世界事件、已知地点
- MemOS 身份与旧记忆（不轮换 `stable_user_id`）

重置：

- 玩家：新角色默认状态
  - 名字「继承者」，性别/性格「未定」，成人档案空
  - `baseDescription = "前任幸存者的继承者"`
  - HP/SP 满（100/100），饥饿/口渴 50，疲劳 0，伤病 `{}`
  - 精神标签 `["健康"]`，内心独白「我继承了一个不属于我的世界。」
  - 技能/装备清空；保留原 `userId` 与末日类型/烈度
- 世界时间：`第1天`、`清晨`、`totalGameMinutes = 360`、`locationScene = "避难所"`
- 背包：清空（与新局当前口径一致；不硬编码物资）
- NPC 对玩家好感：`abs(old) < 20 → 0`；否则 `clamp(old × 0.3, -80, 80)`；关系阶段重算，情感标签清空
- 结算账本与 `lastMidnightSettlementDay` 归 1
- 死亡状态、加速状态、待处理场景缓冲清空
- 派生状态机重建（下次读取按新时间/地点 seed）

保留但清空运行时缓冲：最后一轮场景注记、期望变更、加速摘要。

## 前代纪事摘要

- 数据源：`story_history` 最后 10 条（按现有排序），不新增表/字段
- 文案：
  ```
  【前代纪事】
  - <action 或 "继续生存">：<story 前 60 字>
  ```
- 仅 UI 展示：继承成功后作为一张可关闭卡片出现在叙事区上方；不写入 prompt、不进 MemOS、不改首轮叙事
- 无历史时摘要为空，不显示卡片

## 接口

`GameRepository`：

```kotlin
/** 继承：保留世界，重建玩家；返回前代纪事文本（可能为空）。 */
suspend fun inheritWorldV22(): String
```

步骤：

1. 读旧玩家/世界/历史；构建摘要。
2. 事务内：写新玩家、写重置后的世界、清空背包。
3. 遍历 `npcRuntime` 折算好感，`persistV3State()` 落库。
4. 复位结算账本、运行时缓冲、`stateMachineInstance = null`。
5. 返回摘要。

`GameViewModel`：

```kotlin
fun inheritWorld()           // 防重入；成功清死亡态并保存摘要；失败保留错误
val legacySummary: StateFlow<String>
fun dismissLegacySummary()
```

继承成功后由 VM 生成并发送一次开局行动（与初始化页同一 `OpeningModule` 的最小默认参数），让新角色直接进入首轮叙事。

## 测试

1. **好感折算**：80→24、10→0、-100→-30；emotionalTags 清空、stage 重算。
2. **世界保留**：继承前后 factions/regions/events/NPC 身份与记忆、pairRelations 不变；背包空。
3. **时间/玩家重置**：第1天、360 分钟、避难所；HP/SP 满；技能/装备/伤病清空；账本=1。
4. **摘要**：history 最后 10 条按格式返回；空历史返回空串；不新增表。
5. **重启不受影响**：`restartGame` 仍清空世界与 pair；继承不会走 `clearAllTables`。
6. **VM**：成功清死亡态、摘要可设/可关；重复点击只执行一次；失败保留死亡层。
7. **UI**：死亡层有继承按钮与二次确认，取消不调用。

## 非目标

- 继承者填资料页/命名
- 世界历史摘要注入提示词或 MemOS
- 传家宝/剧情物品保留（留待下一阶段重构）
- 观察者模式、读档

## 验收

- 全量 423+ 全绿，`assembleDebug` 成功；新增测试 ≥8。
- 死亡后可一键继承；世界（势力/区域/事件/NPC/关系）保留；玩家/背包/时间重置。
- 好感折算与阈值精确；摘要只展示；「重新开始」行为不变。
- 无 DB 迁移、无 `!!`、无静默清档。
